with generate_ui_sounds.py when regenerating the other UI sounds.

shortened/filtered steel for TitleNavigate, SlotConfirm, CategoryNavigate and
DisplayAdjust; original shaped noise textures for SlotNavigate and Cancel.
Use build_dark_ui_set.py for the current set instead of the earlier synth generator.
